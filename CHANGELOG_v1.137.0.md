# v1.137.0 - Wake-up watcher for Project Autopilot (2026-10-23, OFF by default)

- New: an idle agent is woken by one fixed line, `[[WAKE w-xxxx]] 2 new messages (from COO, Security). Read them, act, end with DONE:/BLOCKED:.`, when a mail marker in `<workspaceRoot>\shared_state\mail\<agent folder>\<id>.json` addresses it (markers are written by `shared_tools\projects\project.py` and, once registered, by `shared_tools\hooks\sendmessage_marker.cjs`). The line carries counts and sender folder names only, never marker content.
- Switch: `"wakeWatcher": { "enabled": true }` in `app-config.json` (a plain section, read with the new `appConfig.section(id)`; restart to apply). `"dryRun": true` logs what would be sent and types nothing. Default OFF; nothing in the app changes while it is off.
- Code: `src/wakeWatcher.js` (pure decision: gates, rate limits, loop protection, single-flight, heartbeat), `src/wakeWatcherMain.js` (I/O glue: marker reading, persisted memory in `<userData>\wakewatcher.json`, 30 s sweep + fs.watch with 2 s debounce), `main.js` `startWakeWatcher()` (20 s after ready; facts from the live sessions; delivery = `deliverToAgentVerified`, the Keep-going path). Tests: `tests/wakeWatcher.test.js` (31), `tests/wakeWatcherMain.test.js` (9).
- Safety: wakes only attached agents that are idle (transcript quiet 20 s), screen known, no dialog, input box empty, no handoff running, not paused, nobody typed to it in 60 s, throttle GO/SLOW, no CPU/load hold; max 6 wakes/agent/hour, 30/fleet/hour, 20 s fleet gap, 60 s agent gap (config can only tighten); one wake per marker (handled ids persist across restarts); first sight of an agent records its existing markers as seen (enabling never wakes the fleet); unconfirmed delivery is never retried, a definite non-delivery retries once after 3 min; hop limit 4 and ping-pong pause (log events, nobody is messaged); never-wake list reuses `wakeAgent.isNeverWake` (health/finance/legal/personal stems) plus `personal_data` agent flag. It never types anything the owner would have to approve and sends nothing on the owner's behalf.
- Not wired yet: heartbeats (no "work that needs nobody" feed), `*_pending_notes.md` input, ledger "ready task" input (project.py already drops a marker for those). Stopped agents (no attached session) are not woken; they read their mail at the next start.
- Also: `SETUP.md` (generated from `features.js`) gained one paragraph on the `wakeWatcher` section.
- CLAUDE.md (main tree, not edited by this branch): add this entry when the branch is merged.
