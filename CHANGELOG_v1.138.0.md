## v1.138.0 - (2026-10-23) Projects tab: the Project Autopilot ledger on screen (read, answer, Green light)

A new **Projects** entry in the left pane (next to Task List) shows every project in `shared_state\projects\<slug>\` (written by `shared_tools\projects\project.py`).
- **List:** red first (blocked, needs Iddo), then amber (waiting or late, drafts), then green, finished last. Each card: name, owner, a status word (BLOCKED / WAITING / LATE n DAYS / MOVING / DRAFT / DONE) with colour, a one-sentence reason (oldest blocker, or "Finish moved from X to Y"), progress bar against the plan, tokens as a % of the project budget, last activity. The nav entry shows a red count of blocked projects (checked every 60 s while the window is visible).
- **Detail:** big numbers (done %, still to do, token budget) each open the list they count and show their age; burn-up chart (plan, actual, projection at the pace of the last 3 days) and projected finish vs plan; milestones with their checklists and tasks; blocked tasks; ready-to-start tasks; spend against budget (always a % of the week, never dollars); recent events; a draft shows the intake conversation and a **Green light** button (enabled only when System Optimization signed the budget).
- **Blocking questions** show default, deadline and whether the default applies by itself (reversible) or not (irreversible); Yes (take the default), No, or a typed answer. Answers and Green light go ONLY through `project.py` (`answer ... --by=Iddo`, `green-light ... --by=Iddo`), so locking and atomic writes stay in one place; the app writes nothing itself.
- Resilient: the folder is watched (700 ms debounce), a Dropbox file that cannot be read for a moment is retried (3 times) and the last good copy is shown meanwhile; damaged event lines are skipped like project.py does; huge event logs read only the end.
- Code: `src/projects/projectsLogic.js` (pure rules; `derive()` is a port of project.py's and is cross-checked against `project.py show` in the test), `src/projects/main-projects.js` (IPC: main window only, slug/qid validated, no project text in the log), `src/renderer/projects-nav.js` (startup cost: one button), `projects.js` + `styles-projects.css` (loaded on first click, tokens `--pj-*` only). Config: optional `projectsDir` / `projectsTool`, defaults from the workspace folder and shared tools folder (nothing hard-coded).
- Tests: `tests/projects.test.js` (25 tests: rules, project.py cross-check, disk faults, IPC, renderer on a fake DOM, static privacy/wiring/design guards). Needs a full restart; not yet seen in the live app.
