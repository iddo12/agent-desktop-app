## v1.129.0 - My Finance Home: a one-screen view from the finance feed (read-only, synthetic until Security approves real data)

- New **Home** tab, first in My Finance. It reads one read-only JSON file (`finance_feed.json`, schema v0.2) that the Accounting feed tool writes, and shows: a Business / Personal / All switch; source status tiles; a "stale data" strip and a "needs you" strip; balances in their own currency and in NIS with the NIS total; income vs expenses this period and last; VAT position and invoices; a six-period trend. Every figure sits next to its "as of" date. The other tabs and the vault ledger are unchanged.
- **Source freshness:** each source shows a green tick ("Updated 15 Oct") or a red cross ("Not updated 3 Oct") using a 7-day rule the app recomputes itself from the last import date (it does not trust the feed's own flag). Next to it is a plain "Get fresh data" link when one is set in Setup (`financeLoginLinks`, `sourceId=https://...;sourceId=https://...`, https only; empty = no link). The app stores no login, only the address you typed.
- **Safety:** the feed is validated first (`src/finance/feedValidator.js`: required keys, money shape, currencies ILS/USD/EUR, dates, enums, 5000-row caps; a feed with a higher major version is refused; unknown fields are ignored). A bad feed shows "Feed invalid" with the first problem and NO partial figures; the message names the field, never a value. A feed marked synthetic shows a SYNTHETIC DATA badge.
- **Where the file is:** configuration key `financeFeedPath` (env `AGENT_DESKTOP_FINANCE_FEED_PATH`, Setup, else `<work folder>\finance\feed\finance_feed.json`). Nothing is hard-coded. A file inside a cloud-synced folder, on a network share, inside the app folder, or reached through a link is refused (same check as the finance vault). The app never writes the feed.
- New IPC channel `finance-feed` (main window only; takes only a scope string; the renderer never sends a path; the answer is a small pre-filtered view, not the whole feed). Logs carry the channel name and an error code only.
- Tests: `tests/finance-feed.test.js` (21: validator good/bad cases, reader refusals, scope filter, links, IPC guards, log leak check, config keys, no hard-coded path). `tests/finance.test.js` updated for the new channel and tab. Needs a restart.
