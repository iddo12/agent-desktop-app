## v1.130.0 - My Finance: eleven pages from the finance feed (cards, invoices, income, expenses, VAT, accounts, needs you, accountant package, rates, sources, cash flow)

- Eleven new tabs after Home, all read-only and all from the same feed file: **Credit cards** (cycle, due date, charges with category, tag, receipt matched or missing, original currency and NIS, running instalments), **Invoices** (unpaid, overdue, paid; filter and paging), **Income** (by client, kind and month; expected vs received; by currency), **Expenses** (by category, this period vs last), **VAT report** (current and previous periods), **Accounts & transactions** (balances with freshness, masked transactions with a match filter, 50 per page), **Needs you** (items with source and age), **Accountant package** (parts ready of total, last month, and why sending is blocked: prepare-only, there is no send button), **Currencies & rates** (Bank of Israel rates, period-end rates, holdings by currency), **Sources & import** (freshness tick or cross, manual, last full refresh, next due, plain login links) and **Cash flow** (60-day projection chart with value labels, expected items).
- Every figure shows the date it is "as of". The Business / Personal / All switch applies on every page (the package and the cash-flow projection cover everything and say so). Every non-zero count is a button that opens its list, and the Home cards, tiles and strips link to their pages.
- The channel `finance-feed` now takes `{scope, page, offset, filter}`: the page must be on the allow-list, the offset a whole number, the filter one of the page's own values; each answer is one small, scope-filtered page (new `src/finance/feedPages.js`), never the whole feed. The pages are drawn by the new `src/renderer/finance-pages.js`.
- Security hardening of the reader: the feed file is opened once and everything is checked and read on that one handle (regular file, same file as the path, size at most 20 MB and unchanged while reading), so a file swapped in between check and read is refused. A malicious text in a number field never reaches the screen or the log: the first error is the field path plus the rule only. The existing window handler already sends https links to the system browser and denies every new window (`src/main.js` setWindowOpenHandler, will-navigate, will-redirect); a test now pins that.
- Tests: `tests/finance-feed.test.js` 32 (slice 2 pages, paging, filters, scope, IPC page argument, read-only guards, reader handle checks, malicious-value checks). Needs a restart.
