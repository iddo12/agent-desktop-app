# v1.133.0 - My Research gets a second tab: My Recommendations (2026-10-18)

- New tab "My Recommendations" beside "Findings" inside My Research. Weeks newest first (all of W39-W42 today), each collapsible (the newest is open; the open weeks are remembered in localStorage). Each week: the COO's top 5 (#1 full width, #2-5 in two columns, each joined by ideaId to the agent's own item, with "Why the COO ranked it #n"), then one closed group per agent, items sorted by impact, two columns.
- Cards: kind icon (Graphics), impact dots + n/5, effort, cost, status, a "Needs you" strip, a closed "First step and what is needed", and a reply box. "Do it" and "I have a question" only FILL the box (item + week); Iddo edits and presses Send. Nothing auto-sends. After a send a "Replied <date>" chip appears (read back from research\_writes.jsonl, so it survives a restart).
- Data (read-only): `shared_reports\recommendations\<week>\<agent>.json` and `shared_reports\coo\weekly_<week>.json`. `*.bak*` files are skipped; a malformed or oversized file is skipped and counted. No COO file = "Not yet curated by the COO".
- Code: `src/recommendations/service.js` (loader, findRef, replied; tests `tests/recommendations.test.js`), IPC `recs-load` / `recs-write` in `research/main-research.js` (second writer instance from `research/write.js`, finding id `rec:<itemId>`), `preload.js` api.research.recsLoad/recsWrite, `renderer/recs.js` + `styles-recs.css` (loaded on first use by `research.js`, which gained the tab bar). Two allow-list tests updated for the new channels.
- Not changed: the Findings tab, the unread badge (does not count recommendations; Security's call), write delivery rules.
- Verified in the sandbox with the real W39-W42 data: 4 weeks, 111 items, open/collapse, needs-you filter, Do-it prefill, Send to a fixture agent -> pending note + log line + Replied chip, tab switch back to Findings; no console errors.
