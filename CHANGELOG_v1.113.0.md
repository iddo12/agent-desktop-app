## v1.113.0 - Dictation always goes to the agent you recorded it for

Fix: a voice dictation (the Stream Deck key, PHEME) used to be pasted into whichever agent was open when it finished transcribing. If you switched agents while it was being transcribed, it went to the wrong one (2026-10-11: a Health message landed in Video Editing). Agent Desktop now writes the selected agent to `active-agent.json`, PHEME pins that agent when you press the key, and the finished text is delivered to THAT agent through a new `voice-inbox` folder, whatever tab is open. It goes through the normal outbox, so it has the same delivery check, automatic retry and "Not delivered" bubble with Retry / Dismiss as a message typed in the compose box. Nothing on screen changes and no draft or focus is touched. Needs the updated `pheme.py` (already beside the old one; it falls back to the old behaviour until this version runs).
